# Manchao Catrers

Manchao Catrers is a professional catering service website built with modern web technologies.

## Overview

A responsive web application showcasing catering services with interactive gallery, customer reviews, and contact functionality.

## Technology Stack

- **Frontend**: React 19 with TypeScript
- **Styling**: TailwindCSS
- **Build Tool**: Vite
- **UI Components**: Radix UI, Lucide React icons
- **Routing**: React Router DOM

## Features

- Professional service presentation
- Interactive image gallery
- Customer testimonials
- Contact form with email and phone
- Responsive design for all devices
- Modern UI with smooth animations

## Development

### Prerequisites

- Bun
- Package manager (npm, yarn, or bun)

### Installation

```bash
bun install
```

### Development Server

```bash
bun run dev
```

### Build for Production

```bash
bun run build
```

### Preview Production Build

```bash
bun run preview
```
